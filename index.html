⚙️ First-Time Setup

You need to add your JSONBin details to the HTML file. Here's how:

1. Go to jsonbin.io → Sign up free
2. Click CREATE BIN → paste {} → Save → copy the BIN ID
3. Go to Account → API Keys → Create key → copy it
4. Open your HTML file in Notepad and fill in the 3 values at the top:
  JSONBIN_BIN_ID, JSONBIN_API_KEY, ADMIN_PASSWORD
5. Re-upload to GitHub — done! 🎉
